## ⚡ **QUICK START (TL;DR)**

**If you just want to get started NOW:**

1. **Go to:** https://console.cloud.google.com/
2. **Create API key**
3. **Add to `.env`:**
   ```bash
   EXPO_PUBLIC_GOOGLE_MAPS_API_KEY=your_key
   EXPO_PUBLIC_GOOGLE_PLACES_API_KEY=your_key
   ```
4. **Run:** `npx expo start --clear`

**Done!** MapScreen should work now.
